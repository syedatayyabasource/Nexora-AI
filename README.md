# Nexora AI

Nexora AI is a modern AI-powered productivity platform designed to help teams automate repetitive work, understand their data, and improve productivity.

## 🚀 Features

- AI-powered productivity dashboard
- AI automation tools
- Smart analytics
- Team collaboration
- Responsive modern UI
- Pricing plans
- Contact form
- Login interface
- FAQ section
- React Router navigation
- Responsive design for desktop, tablet, and mobile

## 🛠️ Tech Stack

- React.js
- Vite
- React Router
- JavaScript
- HTML5
- CSS3

💡 Why React + Vite?
React was selected because it provides a component-based architecture that makes the application easier to organize, reuse, and maintain.
Vite was selected because it provides fast development startup, efficient builds, and a simple modern setup for React applications.
React Router is used to provide navigation between different pages without requiring a full page reload.
▶️ Run Locally
Install dependencies:
npm install
Start the development server:
npm run dev
Create a production build:
npm run build
